# The figures on the Agent Index page, and how to redo them

Three images, all reproducible from this repo. None of them contains anybody's
real spending: the panel and the chat are rendered over the **demo ledger**,
which is seeded from a fixed RNG and carries the "sample data, not yours"
badge that `panel.py` prints whenever every row in the ledger is `source: demo`.

```sh
# the ledger the pictures are of
export CFO_DATA=/tmp/cfo-demo
python3 cfo-shared/scripts/money.py config timezone America/Sao_Paulo
python3 cfo-shared/scripts/money.py config currency BRL
python3 cfo-shared/scripts/money.py config language en
python3 cfo-shared/scripts/seed_demo.py
python3 cfo-shared/scripts/panel.py

CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

# docs/panel.png -- the wall panel. 1400x1150 is the smallest frame the whole
# page fits in at this width; taller leaves dead space, shorter cuts the
# category bars.
"$CHROME" --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=2 \
    --window-size=1400,1150 --screenshot=docs/panel.png \
    "file:///tmp/cfo-demo/panel/index.html"

# docs/how-it-works.png -- the diagram, whose source is beside this file.
"$CHROME" --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=2 \
    --window-size=1440,740 --screenshot=docs/how-it-works.png \
    "file://$PWD/docs/figures/how-it-works.html"
```

`docs/chat.png` is the one that cannot be regenerated by a command: it is a
real Messages thread, cropped out of `docs/chat-and-panel.png`. The
conversation in it is the demo ledger's figures — the currency question and
the refusal to project on two days of data — so it stays honest as long as
those two behaviours do.

`--force-device-scale-factor=2` on purpose: the index renders these at
roughly half their pixel width, and a 1x capture of a dark UI with thin type
looks soft next to everyone else's.
